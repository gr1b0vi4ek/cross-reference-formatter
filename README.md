Программа автоматизирует оформление перекрестных ссылок в документах Word.
Она находит в файле `.docx` подписи к рисункам, таблицам и формулам, а
также упоминания этих объектов в тексте. На основе найденного программа
расставляет поля `SEQ` для автоматической нумерации и поля `REF` для
перекрестных ссылок. После обработки файл готов к работе: при добавлении
нового элемента в середину документа нумерация пересчитывается
автоматически.

Поддерживаются русские и английские документы. Интерфейс также двуязычный.

## Что делает

- Расставляет поля `SEQ` в подписях рисунков, таблиц и формул. Нумерация
  строится по позиции элемента в документе, поэтому неправильный порядок
  в исходнике исправляется: если «Рисунок 5» стоит перед «Рисунок 3»,
  после обработки номера выстраиваются в правильной последовательности.
- Поддерживает три режима нумерации (выбираются в окне программы):
  сквозная (`1`, `2`, `3`), по разделам (`2.1`) и по разделам и пунктам
  (`2.1.3`). Номер раздела берется из нумерации заголовков; если пунктов
  (заголовков 3-го уровня) в документе нет, применяется формат `2.1`.
- Перед нумерацией элементов проверяет нумерацию заголовков (разделы,
  подразделы, пункты) и исправляет расхождения. Найденные проблемы
  выводятся в журнал, а сами номера заголовков приводятся к правильным.
- Создает закладки на каждый пронумерованный элемент. Имя закладки
  соответствует номеру элемента: `Fig_002_003` – рисунок 2.3,
  `Tab_001_002` – таблица 1.2. При сквозной нумерации имена идут по
  порядку (`Fig_001`, `Fig_002`, …, `Src_001`, …), поэтому в диалоге Word
  «Ссылки → Перекрестная ссылка → Закладка» они отображаются в порядке возрастания.
- Находит в тексте упоминания объектов («рисунок 3», «табл. 2.1»,
  «формула 4», «[5]», «[1, 3-5, с. 20]») и заменяет их на поля `REF`.
  Чтобы ссылка создалась, в тексте должен быть указан номер элемента.
- Обрабатывает формулы OMML, включая размещенные в таблицах (типовая
  верстка «формула слева, номер справа в ячейке»).
- Определяет раздел литературы по заголовку («Список литературы»,
  «Библиография», «References» и т.п.), нумерует источники полями и
  создает на них закладки.
- Сразу показывает актуальные номера в перекрестных ссылках: кэш полей
  `REF` обновляется при обработке, поэтому `Ctrl+A` → `F9` для просмотра
  номеров не обязателен. Заодно удаляются пустые поля ссылок, оставшиеся
  от прежних версий программы.
- Не дублирует работу: если в документе уже есть поля `SEQ` от
  предыдущего прогона, программа подхватывает существующие закладки,
  исправляет «съехавшие» и приводит их имена к текущим номерам.

## Про ссылки в исходном тексте

Главное условие для автоматической расстановки перекрестных ссылок –
наличие в тексте упоминаний с номерами: «рисунок 3», «табл. 2.1»,
«[5]» и т.п. Если таких упоминаний нет, программа их не придумывает –
ссылки нужно будет расставить вручную через Word.

Если в исходном тексте номер не совпадал с реальным положением элемента, а соответствовал несуществующему
(например, «см. рисунок 5», а рисунок на самом деле третий), такая
ссылка останется обычным текстом: программа не угадывает, на что именно
она должна указывать. Заменить ее на правильную можно в Word через
«Ссылки → Перекрестная ссылка → Закладка» – закладки в этом диалоге идут в порядке
возрастания, и нужная находится за пару секунд.

## Порядок работы

1. Запустите `CRF.exe` (или `python main.py` из исходников).
2. Выберите `.docx`.
3. В правом верхнем углу установите язык документа – `ru` или `en`.
   От этого зависит, какие подписи и заголовки программа будет искать.
4. Выберите нумерацию рисунков, таблиц и формул: сквозную (`1, 2, 3`),
   по разделам (`1.1`) или по разделам и пунктам (`1.1.1`). Выбор
   запоминается и применяется при следующем запуске.
5. Нажмите «Обработать и сохранить». Рядом с исходным файлом появится
   копия с суффиксом `_автонумерация.docx`.
6. Откройте копию в Word. Номера в перекрестных ссылках уже актуальны;
   `Ctrl+A` и `F9` нужны только для полного пересчета полей (например,
   после ручной правки текста).

Если нужно проверить документ без изменения файла, нажмите
«Только проверить (без записи)»: программа пройдет по всем этапам,
отразит результаты в журнале, но исходный файл не тронет.

## Запуск из исходников

- Python 3.10 или новее.
- `pip install -r requirements.txt` – установит `python-docx`.

Затем `python main.py`.

## Требования

- Python 3.10+ для запуска из исходников.
- Windows 7+ для готового `.exe`.

## Обратная связь

Если встретился документ, который программа не разбирает, откройте Issue
и приложите фрагмент (минимум – заголовок раздела и пример подписи).
Регулярные выражения дорабатываются по мере появления новых форматов.
Pull requests также принимаются; для крупных изменений желательно
сначала обсудить их в Issue.
